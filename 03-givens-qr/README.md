# QR Decomposition with Givens Rotations

Solution of linear systems using QR decomposition based on Givens rotations for dense and banded matrices.

## Implemented

- matrix generation with a known exact solution;
- QR decomposition using Givens rotations;
- algorithms for full and banded matrices;
- compact storage of a banded matrix;
- back substitution for the triangular system;
- residual and solution-error calculation;
- operation counts and runtime benchmarks;
- export of benchmark results to CSV.

## Run

```bash
python code/main.py
```

## Files

- `code/main.py` — original implementation;
- `report/report.pdf` — report with algorithms, experiments and conclusions.
